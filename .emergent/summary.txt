<product_requirements>
The goal is to build a full-stack CityHub Emergency Management Dashboard, serving central administrators and local zone managers.

**Initial Requirements (MVP):**
1.  **Master View**: City-Wide Administration Dashboard for central administrators, providing oversight of zones, cameras/sensors, user management, alerts, and analytics.
    *   Features: Master Dashboard Home (city map, live status, global widgets like incident overview), All-Zone Incident Center (master incident table with filtering, actions like view details, assign/escalate/resolve), All Cameras/Devices Table (master searchable list, bulk actions, remote control), Event Analytics (city heatmaps, zone comparison, data export, predictive AI), User & Role Management (user table with CRUD, zone access, role policy editor), System Health/Monitoring (network map, alert thresholds, live graphs), Settings & Integrations, Audit Logs.
    *   No live interactive city maps; static/offline maps or filter-based lists are acceptable. All modules must be fully functional, not partial demos.
2.  **Zone/Area (Local Role) Dashboard**: For local managers/operators, limited to their assigned area.
    *   Features: Zone Map (only selected zone), Incident Table (zone-specific), Cameras & Devices (zone-specific), Crowd Analytics (zone-specific), SOS Alerts.
    *   Role-limited actions/views, local settings.
3.  **UI Controls, Buttons, and Permissions Logic**: Differentiating controls for Master vs. Local views, comprehensive feedback.
4.  **Visual/UI/UX**: Emphasis on modern design, Shadcn UI, Tailwind CSS, specific font/color guidelines, responsiveness, tooltips, micro-animations, no system-UI fonts, proper spacing, no universal transitions.

**Improvement Requirements (Post-MVP, detailed):**
The user provided detailed sample data and specific layout/logic for enhancing each module:
*   **Incident Center**: Interactive cards/table, filtering, detailed view modals, assign/resolve/escalate actions with feedback.
*   **Devices & Cameras**: Grid/list view, status icons, health, maintenance assignment, reboot functionality.
*   **Zone Management**: Zone cards, static Ujjain map overlay with clickable zones, filtering.
*   **User Management**: Role summary, user table with CRUD actions, deactivate.
*   **Alerts & Notifications**: Notification drawer, mark as read, resolve, escalate actions, sound/visual feedback.
*   **Analytics**: Bar, line, pie charts (density, frequency, health), trend cards, export.
*   **System Health**: Global summary, device health table, restart device, report issue, schedule maintenance.
*   **Global Navigation**: Sidebar/top bar for module switching, home/landing with quick summary cards.
*   **Role-Based Controls**: Admin (all), Operators (their zones), Responders (assigned incidents/alerts).
*   **Modals/Dialogs**: Required for all critical actions with confirmation.
*   **Visual Feedback**: Success, loading, error states for all actions.
</product_requirements>
